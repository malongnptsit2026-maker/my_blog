# 📝 Simple Blog

A minimal blog web app built with **Node.js**, **Express.js**, and **EJS**.
Posts are stored **in memory** (no database) — they reset when the server restarts.

## ✨ Features
- 📄 View all posts on the home page
- ➕ Create new posts
- ✏️ Edit existing posts
- 🗑️ Delete posts
- 📱 Responsive, clean styling (custom CSS)
